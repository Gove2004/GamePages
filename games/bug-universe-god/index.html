// Developer's Note

开发者的话

我很抱歉，虫虫宇宙神真的不是一款好玩的游戏。（开发者都这样说）

其中最大的一个错误就是，追求设计性而抛弃了游戏性。另一个同样致命的错误就是，追求内容量而失去内容质。

具体点，犯了什么错误？

1. 强硬结合原本的 Archipelago Pale 的故事和 Bug 的主题。
2. 无引导，无提示，自己无从得知的负反馈和无的正反馈。
3. 合成逻辑毫无规律，不可预测，只能穷举。

游戏在设计阶段未能预测到后续的计划崩坏。并且目前游戏表现远超原型以至于我觉得还行。我接下来只会修复小 bug，做好小引导，但改变不了这艺术大粪的本质。

遗憾的是，作为玩家，你什么都做不了。没有人能受得了它恶心人，包括我。

— Gove，策划 / 程序 / 剧情文案 / 制作人
