design_doc / UnReal Objects.md

设计前提

不可能物体是在现实世界中，不可能客观存在的事物，

只会在二维世界存在的一种图形。

这些图形通过"欺骗"大脑的透视处理机制，

展现了二维与三维逻辑的冲突。

——以上为设计文档《UnReal Objects.md》的开篇原文。
游戏把这段文字做成了可以走进去的棋盘格：格子是二维的，走法却按三维空间写。

// 03 · HOW TO PLAY

操作：捡牌，然后按下它

走格子用 W A S D · 撤销用空格 · 动作牌用对应的字母键

W A S D

四方向移动GameManager.SIZE = 64 px

W 上、A 左、S 下、D 右，每次走一格。角色用 RayCast2D 试探前方， 有墙就走不动——这是唯一"守规矩"的移动方式。

Space

撤销上一步input: uodo → player.undo()

输入映射名为 uodo，按下后调用 player.undo()， 把刚才那一步整段倒放回去。动作牌走得越长，撤销倒放得越久。

Shift+Ctrl+Space

调试模式input: debug

源码中保留的 debug 输入映射，用于直接灌入预设动作列表， 跳过拾取流程。相关代码目前处于注释状态。

A – Z

字母动作牌Actions/Tres/*.tres

地图上散落着字母牌，走上去即拾取。每个字母被绑成快捷键，按下后角色 依次执行它记录的一串方向命令——这是唯一能走出"不可能路径"的方式。

WW_Walk
AD_Walk × flip
SS_Walk
DD_Walk

// 04 · FLOORS

五张地图，四种不可能物体

Maps/0.tscn – Maps/4.tscn · 展开一层看它的机制、可用牌与提示原文

F00 未命名Maps/0.tscn 教学关 · 只有两张牌 AD

整个地图只有两块动作牌：A（Left+1）与 D（Right+1），起点在 (416, 352)。 这是让玩家先理解"按字母 = 走一步"的入门格。

"通常你不会在这里，除非有 bug"0.tscn 内唯一的提示区域（L215-216）
F01 三角Triangle 入门关 · 彭罗斯三角形 ADSW★1

四张基础牌 A / D / S / W 组成最初的四个方向，本关共 11 个提示区域， 一路教到"秘密通道"。Flag2 是隐藏终点，star_flag = 1，位置 (1248, -96) —— 在地图边界之外，只能靠违背直觉的位移抵达。

"站着！我让你动了吗！？" → "哇，秘密通道" → "空格 撤消上一步"1.tscn 提示序列（L237-288）
F02 立方Cube 不可能立方体 · 棱角同时朝前和朝后 DJQT★2

牌组换成 Q（上1左1）、T（右3下1）、J（下3左1）与 D。 三个"斜向"动作让格子上的前后关系开始打架，13 个提示区域一路追问同一个问题。 隐藏终点 star_flag = 2 在 (2336, 1312)。

"刚才你为什么不直接向左走呢？" → "我觉得你可能被骗了" → "死路一条"2.tscn 提示序列（L237-298）
F03 阶梯Stair 埃舍尔阶梯 · 上下却回到原点 GNSU★3

本关有 N（上1右1下1）、G（左1下2右3上4）、U（下1左2上2）与 S。 G 与 U 的长串命令会绕一圈回到附近，正是"无限循环阶梯"的机制化身。 隐藏终点 star_flag = 3 在 (1120, 800)。

"看，两个终点" → "猜猜你为什么总是见我？" → "哈哈哈"3.tscn 提示序列（L237-273）
F04 音叉Fork 恶魔音叉 · 追逐战 AEIOQZ★4

唯一带敌人的关卡：14 个红色的 Dust（"恶魔"）每 5 秒随机朝一个空方向走一格， 碰到玩家即判负。可用牌为 A / E / I / O / Q / Z，其中 Z 是"右1左1右1" ——一次净位移一格，但中途的往返让追击者算不准。 隐藏终点 star_flag = 4 在 (416, -608)。

"当心魔鬼" → "那边有很多恶魔" → "感谢游玩 （2025.3.30 by Gove）"4.tscn 提示序列（L252-298）

// 06 · CATALOG

四种不可能物体

Objects/ 目录下的四份素材 · 定义引自设计文档原文 · 点图让它转一圈

彭罗斯三角形

Objects/Triangle · boot_splash

由三个直角连接的条形构成，看似闭合的三角形，但实际无法在三维空间中存在。

同时也是游戏的启动画面与窗口图标（project.godot 的 boot_splash/image 与 config/icon 都指向它）。

不可能立方体

Objects/Cube · 关卡 2「立方」

立方体的边缘连接方式违反透视规律，部分棱角看似同时朝前和朝后。

对应第 2 关的关卡图标（level_menu.tscn 中 Name = "Cube" / CName = "立方"）。

埃舍尔阶梯

Objects/Stair · 关卡 3「阶梯」

无限循环的阶梯，始终向上或向下却回到原点，违背重力法则。

对应第 3 关的关卡图标（level_menu.tscn 中 Name = "Stair" / CName = "阶梯"）。

恶魔音叉

Objects/Fork · 关卡 4「音叉」

物体末端看似同时具有三个和两个分叉，无法确定其真实结构。

对应第 4 关的关卡图标（level_menu.tscn 中 Name = "Fork" / CName = "音叉"）；本关的 14 个红色敌人也叫 "Dust"。
