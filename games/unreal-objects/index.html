// title screen

不可能物体是在现实世界中，不可能客观存在的事物，

只会在二维世界存在的一种图形。

这些图形通过"欺骗"大脑的透视处理机制，

展现了二维与三维逻辑的冲突。

放下习惯性的空间直觉——玩家在棋盘格上移动一步，
屏幕上的位移却可能同时朝三个方向发生。

// HOW TO PLAY

操作：一步一错觉

WASD 走格子 · Space 撤销 · 特殊键触发不可能位移

W A S D

方向移动

每个键让角色沿棋盘格走一格：上 / 左 / 下 / 右。绿色与棕色相间的草地格子是你的全部舞台。

Space

撤销一步

走错了？空格回退上一步。游戏内置了完整的步骤记录（源码中该动作名为 uodo），允许你反复试错。

N

不可能位移

某些格子上的特殊键会同时朝多个方向移动——例如 N = 上+1 右+1 下+1。一步走出三个方向，空间关系当场崩塌。

U / Q

触发机关

走到特定格子会浮现 U 等按键标记。按下后角色执行一次违反透视的位移，穿过花苞障碍、抵达红旗。

// CATALOG

四种不可能物体

源码 Objects/ 目录下的四个场景 · 构成全部关卡

01

彭罗斯三角形

Objects/Triangle

由三个直角连接的条形构成，看似闭合的三角形，实际无法在三维空间中存在。它也是游戏的启动画面与图标。

02

不可能立方体

Objects/Cube

立方体的边缘连接方式违反透视规律，部分棱角看似同时朝前和朝后。

03

埃舍尔阶梯

Objects/Stair

无限循环的阶梯，始终向上或向下却回到原点，违背重力法则。

04

恶魔音叉

Objects/Fork

物体末端看似同时具有三个和两个分叉，无法确定其真实结构。
