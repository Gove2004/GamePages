游戏介绍

Unreal Objects 是提交到「第 2 届 Godot 游戏创作节」的 GameJam 作品，主题围绕“不可能物体”。它把彭罗斯三角形、不可能立方体、埃舍尔阶梯、恶魔音叉等只能在二维图像中成立的结构，转化为一款不依赖直觉的解谜/实验游戏。

这个项目的重点是“二维与三维逻辑冲突”。玩家看到的画面看似合理，但真实空间关系未必成立；作品试图让玩家放下习惯性的空间直觉，重新理解移动、拾取、提示与关卡结构。

作品亮点

  • 使用 Godot 制作，短周期内完成整体框架、命令模式和玩家动画逻辑。
  • 围绕“不可能物体”设计关卡与交互，强调反直觉体验。
  • 包含可拾取物、提示互动和多关卡结构。
  • 支持中英双语文本，并在 itch.io 提供 Windows 下载。
