## 首页改版（index.html）
- 用户觉得个人游戏作品集首页「不好看」，要求改进。
- Ardot 画布适配器连接失败（routeKey 不存在，NO_ADAPTER），无法在画布上做设计，改为直接改真实网站文件 `index.html`（即上线成品）。
- 用户选择方向：**更大胆的新视觉**；结构改为 **「全屏轮播 + 作品列表」**，明确不要 Spotlight / About / Stats / 联系 CTA 等新增板块。
- 改动要点：
  - Hero 改为 5 款游戏自动轮播（5.2s 切换，箭头/圆点/键盘，hover 暂停），每款用各自标志色（标题高亮+按钮+进度点）。
  - 作品区由卡片网格改为编辑式列表（序号+缩略图+标题/标语/标签+平台+箭头，hover 染标志色）。
  - 背景由 5 色极光改为中心冷光晕 + 径向遮罩细网格，更统一。
  - 页脚收为一行式。
- 约束：项目规则「无 CDN、字体用系统栈」，标题字无法引外链；用超大字号+极重字重+紧字距做大胆感。若用户想要更有性格字体，可自托管免费显示字体（不碰 CDN）。
- 封面图路径已确认存在：games/<slug>/cover.jpg × 5。

## 第二轮：细节工艺升级（用户反馈"设计细节太垃圾，看具体游戏详情页的细节就很好"）
- 读取了 5 个游戏详情页，提炼其工艺语言：等宽字体 kicker（`// STORY`、`KEY ITEMS`、编号 `01/02/03`）、eyebrow 引线（`::before` 短线）、左侧竖线 quote-line、衬线引言、截图暗→亮揭示（"靠近才能看清"）、呼吸光球/辉光、战场动画、滚动浮现、字距与留白讲究。
- 在**保持轮播+列表结构不变**的前提下，把上述语言搬回首页：
  - 全站引入 `--mono`（Cascadia Code 等宽）与 `--serif`（Georgia/Songti）两套字体变量，用于标签/编号/引言。
  - 导航：品牌标加呼吸辉光动画；右侧加 `Portfolio · 2026` 等宽小标。
  - 轮播：eyebrow 加引线、标题 accent 改渐变文字、底部加随当前作品变色的辉光 `.slide-glow`、底部自动播放进度条（JS 重启动画 + 跟随 accent 变色）、滚动提示。
  - 作品列表：区块标题加 `// Selected Works` 等宽 kicker + 引线；行 hover 时左侧生长 3px accent 强调条 + 缩略图叠加"查看 →"蒙层 + 辉光；编号/平台/标签全改等宽大写；标语改衬线斜体；箭头 hover 位移。
  - 页脚：品牌标 + `Gove · Indie Game Dev` 等宽标。
- 关键 CSS 技巧：`color-mix(in srgb, var(--accent) X%, transparent)` 做半透明强调色；进度条用 `transform: scaleX` + 强制重排重启动画。
